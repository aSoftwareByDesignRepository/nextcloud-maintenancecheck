# Security Policy

## Supported versions

Security fixes are applied to the latest published MaintenanceCheck release that supports a still-supported Nextcloud major version (see `appinfo/info.xml` dependencies).

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security findings.

Email the maintainer listed in `appinfo/info.xml` (`info@software-by-design.de`) with:

- a short description of the issue
- steps to reproduce (or a proof of concept)
- affected version / Nextcloud version if known

We will acknowledge receipt and coordinate a fix and disclosure timeline. Thank you for helping keep Nextcloud instances safe.
